# README artwork

These five images are documentation-only presentation assets for VoxAster. They are not application resources and do not change the product UI.

The silver acoustic forms are illustrative, AI-generated artwork. Every application interface is a genuine [VoxAster 3.7.0 screenshot](../images/README.md), placed intact with proportional scaling, a rounded frame and shadow. No controls, UI text or capabilities were fabricated. The original screenshots remain unchanged and use synthetic demo material, not private recordings or projects.

The Performance silence motif illustrates an existing app-level pause; it is not measured audio or an emotional-acting feature. Timing and loudness controls retain their documented limitations.

Typography is rasterized from an installed system font. No proprietary font files are included. Unnecessary EXIF/Photoshop metadata was removed without recompressing the images or changing decoded pixels.
